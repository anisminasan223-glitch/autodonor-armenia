# AutoDonor Armenia

Сайт для заявки на оценку автомобиля.

## Что делает сайт
- Клиент заполняет форму.
- Можно выбрать до 10 фото/видео, до 16 МБ каждый файл.
- При нажатии «Ուղարկել հայտը՝ գնահատման համար» браузер отправляет форму на `/api/lead`.
- Сервер отправляет письмо на `autodonorarmenia@mail.ru` с текстом заявки и реальными файлами во вложениях.
- Отдельные кнопки: звонок, SMS и WhatsApp.

## Важно
`index.html` нельзя открывать как `content://` или `file://` и ожидать автоматической отправки: сервер `/api/lead` в таком режиме не запущен. Сайт должен быть размещён вместе с Node.js-сервером и открываться по HTTPS.

## Настройка Mail.ru
1. Создайте пароль для внешнего приложения в настройках безопасности Mail.ru.
2. Скопируйте `.env.example` в `.env`.
3. Укажите:
   - `MAIL_USER=autodonorarmenia@mail.ru`
   - `MAIL_PASS=ВАШ_ПАРОЛЬ_ВНЕШНЕГО_ПРИЛОЖЕНИЯ`
   - `MAIL_TO=autodonorarmenia@mail.ru`
4. Выполните `npm install` и `npm start`.

SMTP: `smtp.mail.ru`, порт `465`, SSL/TLS.

## Самопроверка
- `node --check server.js` — синтаксис сервера.
- JavaScript страницы проверяется через `node --check`.
- ZIP проверяется командой `unzip -t`.

Реальную доставку в Mail.ru невозможно подтвердить без действующего пароля внешнего приложения и запущенного сервера. Код не показывает «успешно», если `/api/lead` или SMTP возвращают ошибку.
