AutoDonor Armenia — запуск

1. Распакуйте архив.
2. Скопируйте файл .env.example и переименуйте копию в .env
3. В .env оставьте:
   MAIL_HOST=smtp.mail.ru
   MAIL_PORT=465
   MAIL_USER=autodonorarmenia@mail.ru
   MAIL_TO=autodonorarmenia@mail.ru
   PORT=3000
4. В MAIL_PASS= вставьте ПАРОЛЬ ВНЕШНЕГО ПРИЛОЖЕНИЯ Mail.ru, который был создан для SMTP.
   Обычный пароль от почты использовать нельзя.
5. На компьютере с Node.js 20+ выполните:
   npm install
   npm start
6. Откройте сайт через адрес сервера. Проверка сервера: /health

Важно:
- Пароль Mail.ru никому не отправляйте.
- Форма сайта не показывает успех, если письмо реально не ушло: сервер возвращает ошибку.
- Фото и видео отправляются как настоящие вложения письма.
- Максимум 10 файлов, размер одного файла до 16 МБ.
